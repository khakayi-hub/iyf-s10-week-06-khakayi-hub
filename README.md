## Project Description
Built a dynamic User Directory web application that fetches and displays user data from an external API. Implemented real-time search, loading states, and error handling using modern JavaScript (async/await and fetch API), with efficient DOM rendering for a smooth user experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript


## Features
- API DATA FETCHING
  Fetches user data from external API.
  Uses modern fetch() with async/await
  
- ASYNCHRONOUS DATA HANDLING
   Uses async/await for clean ,readavble code.
   Implements try/catch/finally for error handling
  
- LOADING STATE
   Display a"Loading..."indicator while fetching data.
   
  

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
   OR
   Run `npm install` then `npm start`
